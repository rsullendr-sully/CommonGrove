# Common Grove — Roadmap

The roadmap preserves the full direction. It does not authorize all listed work at once. Each release begins only after the previous release gate is reviewed.

## Release 0 — Concept validation (active)

Build a scripted 2.5D prototype with one companion, one garden, representative accomplishments, visible changes, a welcome-back summary, and one meaningful choice.

**Gate:** Employees understand the loop, show interest in returning, prefer autonomous growth, and do not experience strong surveillance or role-fairness concerns.

## Release 1 — Product and system design

Define the event contract, reward economy, creature behavior, garden state, privacy rules, art direction, architecture, analytics, and MVP acceptance criteria.

**Gate:** Requirements are testable; privacy, fairness, art, and economy assumptions have named owners and evidence.

## Release 2 — Technical foundation

Implement identity, event ingestion, idempotency, persistence, deterministic simulation, audit history, and administrative recovery controls.

**Gate:** Events process once, state persists, failures are diagnosable, simulations are replayable, and personal data can be deleted correctly.

## Release 3 — Personal-garden MVP

Deliver the complete personal loop: one autonomous companion, persistent growth, return stories, occasional choices, and companion development.

**Gate:** The garden progresses without management, is understood quickly, and performs well on ordinary workplace laptops.

## Release 4 — Social neighborhood

Add opt-in coworker visits, gifts, reactions, friendship visits, granular permissions, and a shared team space.

**Gate:** Social activity is safe, private, asynchronous, and free of ranking pressure.

## Release 5 — First real integration

Connect one reliable source in shadow mode, validate mappings and duplicates, then enable a small voluntary pilot.

**Gate:** Processing is reliable, understandable, reversible, privacy-reviewed, and demonstrably equitable across roles.

## Release 6 — Pilot and balancing

Run a voluntary pilot, measure return behavior, attachment, burden, privacy concerns, fairness by role, and processing health.

**Gate:** Continue, revise, or stop based on agreed evidence rather than feature completion alone.
